Danger Zone

🔴 SECRET_KEY — Never change this after first run
The SECRET_KEY is set in your .env file or docker-compose.yml. Changing it will immediately invalidate ALL kid PINs, the admin PIN, and all active sessions. Every child profile with a PIN set will need their PIN re-entered. Set this once and never touch it again.
🔴 Database Path — Set in docker-compose.yml only
The database path (KIDTUBE_DB_PATH) must be set before the app starts. It cannot be changed here. Changing it incorrectly will cause the app to fail to start.
